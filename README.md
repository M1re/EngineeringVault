# Engineering Vault

A public knowledge base about what a **staff software engineer** is expected to understand
deeply — written to *understand* the stack, not just memorize it for interviews.

Notes are authored in [Obsidian](https://obsidian.md) and published as a website with
[Quartz](https://quartz.jzhao.xyz) via GitHub Pages.

## Sections

Programming · Computer Science · Data Persistence · Networks · Architecture ·
AI & ML · Security · Cloud · DevOps

## Repository layout

```
Vault/       Obsidian vault — all notes are authored here (open this folder in Obsidian)
content/     generated by Quartz Syncer from Vault/ — never edit by hand
AGENTS.md    rules for every coding agent (CLAUDE.md imports it)
.claude/     agent automation: commands, skills, reviewer, hooks, plugins
docs/        local setup & workflow notes (not published)
scripts/     setup, the commit-time export, dashboard/cover helpers
.githooks/   pre-commit export hook (enabled by npm run setup)
quartz/      static-site generator (Quartz v4)
```

## Setup on a new machine

```powershell
winget install OpenJS.NodeJS.LTS
winget install Git.Git
winget install Obsidian.Obsidian
# reopen the terminal so git/node are on PATH
git clone https://github.com/M1re/EngineeringVault.git
cd EngineeringVault
```

Open `EngineeringVault/Vault` as a vault in Obsidian, trust its plugins, and enable
**Settings → General → Command line interface**. With Obsidian running, in a new terminal:

```powershell
cd EngineeringVault
npm run setup
```

If PowerShell blocks scripts: `npm.cmd run setup`.

In Claude Code, accept the prompt to install the project plugins (Chisle, oh-my-claudecode, Obsidian skills).

## Publishing

Obsidian Git commits and pushes 10 min after the last edit (now: **Obsidian Git: Commit-and-sync**).
The commit hook exports `publish: true` notes into `content/`; the push deploys the site.

```powershell
npm run export              # export without committing
git commit --no-verify      # commit without exporting
npx quartz build --serve    # preview at http://localhost:8080
```

Hook log: `.git/quartz-sync.log`. The repo is public: `publish: false` hides a note from the site only.
