# Computer Science

The theoretical foundations that make you reason about correctness and cost, not just make things work.

> [!abstract] Scope
> Algorithms, data structures, complexity analysis, and the computational theory underneath everyday engineering decisions.

## Planned topics

- Big-O & complexity analysis
- Core data structures (arrays, hash maps, trees, heaps, graphs)
- Sorting & searching algorithms
- Recursion & dynamic programming
- Graph algorithms (BFS, DFS, shortest paths)
- Hashing
- Computation theory basics (P vs NP, state machines)
